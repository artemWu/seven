# Seven

Technical starter for the 7barbershop website. The visual design and production content will be added from the approved Figma file.

Built with Next.js, vinext, Vite and the existing Cloudflare/GitHub Pages pipeline.

## Local development

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```

## Deploy

Use the existing GitHub Pages deployment workflow for repository `artemWu/seven`.
